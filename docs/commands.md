# 聊天命令

群里任何人发一条以 `/` 开头的消息（也认全角 `／`，前面可以带 @小号），就是命令。命令由**插件运行时直接执行**，不经过模型；没注册的 `/xxx` 当普通聊天。群里没有"主人"：所有命令每个人都能用，只有取消定时限定为设置人。

`/help` 会列出下面所有命令和四种模式。

本文成员称呼、群名和验收标识均已替换为通用示例，不包含真实聊天记录或账号数据。

## 命令一览

| 命令 | 别名 | 作用 | 会打断正在思考的回答 |
| --- | --- | --- | --- |
| `/help` | `/帮助` | 列出所有命令和发言模式 | 否 |
| `/mode [free\|infer\|at\|silent]` | `/模式` | 查看/切换发言模式；也认 `at-only` `mention` → at，`auto` `smart` → infer，`quiet` `off` → silent | 是 |
| `/wait [静默秒数] [上限秒数] \| reset` | `/等待` `/合批` | 查看或设置合批等待：群里静默几秒算一批（0.5–30）、一批最多等几秒（不小于静默，≤120）；所有模式统一，重启后保持，`reset` 恢复配置 | 否 |
| `/mute [分钟]` | `/闭嘴` | 临时禁言，默认 30 分钟，最长 1440 | 是 |
| `/unmute` | | 解除禁言 | 是 |
| `/status` | `/状态` | 模式、禁言剩余、今日处理批次和发言数、上下文条数、记住几位成员 | 否 |
| `/memory` | `/记忆` | 看机器人记住了**你自己**什么 | 否 |
| `/forget <主题\|all>` | `/忘记` | 删掉关于你自己的某条或全部记忆 | 是 |
| `/reset` | | 清空短期上下文（不动长期记忆） | 是 |
| `/ask <问题>` | `/问` | 认真回答：先回"收到，想一下"，插队交给模型，思考强度 high，不受限速，禁言/静音/只回@时也回答 | 是 |
| `/tldr` | `/总结` | 先回"收到，翻翻记录"，插队让模型总结最近的聊天 | 是 |
| `/model [模型名\|provider/模型名\|reset]` | `/模型` | 不带参数：当前模型、思考强度和可用模型；带参数：切换（只影响之后的回复）；`reset` 恢复配置默认 | 否 |
| `/think [off\|low\|high\|max\|on]` | `/思考` | 查看或调整思考强度；`on` = high，`开`/`关` 也可以 | 否 |
| `/cron …` | `/定时` | 定时发消息，见下文 | 否 |
| `/attack <昵称\|@TA>` | `/嘲讽` `/怼` | 持续嘲讽某人，见下文 | 是 |
| `/unattack` | `/停止嘲讽` | 停止嘲讽 | 是 |
| `/comfort <昵称\|@TA>` | `/安慰` | 持续安慰某人，见下文 | 是 |
| `/uncomfort` | `/停止安慰` | 停止安慰 | 是 |

直接回复的命令统一以"已执行："开头，例如 `已执行：切换为 at（只回@：…）`、`已执行：安静 30 分钟`。

## 模型与思考强度

- 切换前会向 DSH 查询：模型必须在 DSH 的模型目录里（按 id 或名字匹配，不区分大小写；同名的多个模型要写成 `provider/模型`），思考强度必须是该模型支持的档位，否则回复"没改成：原因"，**不会切到一个调用必失败的状态**。
- 换到不支持当前思考强度的模型时，自动改为 off，并在回复里说明。
- 改动落盘，重启后保持；`/model reset` 回到配置（`model.*`）的值。控制台和 `/wechat status` 显示当前值。
- `/ask` 临时用 high；当前模型不支持 high 时按当前强度回答。
- 正在进行的那次模型调用不受影响。

## 发言模式

| 模式 | 什么时候调用模型 |
| --- | --- |
| `free` | 每一批消息都交给模型，它自己决定要不要接话；冷场时可以主动说话（`idleMinutes` > 0） |
| `infer`（默认） | 程序判断这批里有消息**可能在跟它说话**（addressed = you 或 maybe：@、引用它、叫名字、顺口提到名字、刚和它聊完的人接着说）才调用回复模型；其余作为上下文，也可进入独立后台记忆学习 |
| `at` | 只有被 **@** 或被**引用回复**（私聊算 @）才交给模型 |
| `silent` | 不调用模型、不说话；命令和定时照常 |

只要某条消息 addressed = you（被 @、被引用、被叫名字），模型就必须回复，沉默会被纠正一次。模式按群保存，重启后保持；控制台按钮、`wechat_bot` 工具、`/mode` 改的是同一个状态。

最近接话对象按成员分别保存，其他成员得到回复不会覆盖你自己的接话机会；明确开始 @/引用其他人后，普通跟进不再沿用找机器人的状态。

## 合批等待与续发（/wait）

```
/wait          查看当前设置
/wait 3 8      群里静默 3 秒算一批，一批从第一条起最多等 8 秒
/wait 3        只改静默；比上限还长时上限跟着调高
/wait reset    恢复配置（behavior.quietMs / maxWaitMs，默认 3 / 8）
```

- **合批**：群里每来一条普通消息，静默倒计时重新开始；静默到点、或从这批第一条起到了上限，就把攒下的消息一次交给模型，多人连着说也只回一次。机器人思考或发送时新消息只排队，空下来再计时。攒满 20 条或 6000 字立即处理。
- **所有模式用同一组时间**；`/wait` 的设置落盘，重启后保持，`/help` 末尾显示当前值。静默 0.5–30 秒，上限不小于静默、不超过 120 秒，超出范围回复"没改成：原因"。
- **续发重写**：这一批里说过话的人，在这批交给模型后的**一个静默期内**又补了一句、且回复还没发出 → 草稿作废，带上补充重写一次。全由脚本判断（看发送者 id 和到达时间），每条消息最多重写一次，所以一直有人说话也拖不住回复。别人的话、更晚的补充进下一批；命令不触发；分几条发送的回复会发完。`/attack` `/comfort` 期间只有目标本人的补充会触发。日志显示"某某 等人又说了话，合并后重新回复"。

## 记忆与小号窗口

背景、兴趣、持续事项和称呼偏好可以从自然自述主动学习，不必附带“记住”。后台学习独立限速、不会拖住回复；`/memory` 查看自己的已接受笔记。`/forget` 同时取消在途学习，并禁止删除前的旧证据重新写回；之后新的自述仍可成为证据。明确要求记住的玩笑称呼按本人自称或互动约定归属，不升级为真实亲属事实。

启用发送配置 `desktopControl:true` 后，控制台已有的显隐开关显示“显示小号 / 登录”。点击进入小号专用桌面；小号未运行时先打开登录窗口。扫码或手机确认后，点击左上角“返回主桌面（微信继续在后台运行）”。返回后若发送尚未准备，点“重新准备”或重新选择目标会话。后台发送不会主动切桌面；显示小号期间暂缓自动发送。此操作不退出工作微信，也不清空小号数据。

## /attack /comfort 定向互动

```
/attack 成员甲        /attack @成员甲        /comfort 成员乙        /unattack          /uncomfort
```

**说不说、对谁说，全部由脚本按数据库里的发送者 id 决定；模型只写内容。**

- **找人**：身份只认 wxid，名字都是挂在它上面的标签。命令里 @ 了某人 → 就是 TA（最可靠）；否则在每个人**当前**的所有叫法里找——群昵称、昵称、小号给的备注、微信号、wxid——先精确匹配，再按"包含"唯一匹配。重名、多个候选、找不到、指向机器人自己，都回复"没开始：原因"，不会猜。候选来自适配器实时读的群成员列表，加最近发过言的人。
- **改名**：开始之后目标改昵称/群昵称，照样认（按 wxid）；控制台和提示词里显示 TA 的新名字。
- **开场**：回"已执行：开始嘲讽 成员甲。TA 说一句我回一句，/unattack 停止"，然后插队让模型对 TA 说第一句。
- **之后**：每一批消息里只看目标本人发的；没有就跳过（日志 `跳过 N 条（正在专门回应某人）`），**别人 @ 它也不理**。目标发了几条就合成一批，**只回一次**；目标不说话，机器人就不说话，不会刷屏或自言自语。模型这时必须回复，回复记为回应目标。
- **同一时间只有一个目标**：再发 `/attack` 或 `/comfort` 会替换掉原来的，并在回复里说明；`/unattack` 只停嘲讽，正在安慰时会提示用 `/uncomfort`。没找到人的命令不影响正在进行的互动。
- **结束**：`/unattack` `/uncomfort`，或目标连续 1 小时没说话（`engagementIdleMs`），之后恢复按发言模式正常工作。
- **和其它状态**：优先于发言模式（`at` 模式下也会回目标）；`/mute` 和 `silent` 让它暂停（目标的话照样记入上下文）；限速、熔断照常生效；互动期间不做冷场主动发言。状态落盘，重启后继续。控制台、`/wechat status` 显示"正在嘲讽 成员甲"。
- 嘲讽要像群友斗嘴，提示词要求不涉及人身攻击、歧视、隐私。
- **和其它命令**：互动只过滤**普通聊天消息**；命令不受影响，任何人照常可用：`/ask` `/tldr` 照常回答发命令的人，`/status` 显示"正在嘲讽 成员甲"，`/mode` `/model` `/think` `/cron` `/help` 等照常执行。会打断的命令（`/mode` `/mute` `/ask` 等）打断正在给目标想的回复，那批目标消息稍后按新状态重想。目标本人也能发 `/unattack`（群里没有特权身份）。
- **开场白作废**：开场白还在生成或分条发送时，来了 `/unattack` 或换了目标，开场白不再发出（日志"互动已停止或换了对象"）；正在回应目标的多条回复也会停在当前这条。

## 命令为什么快、和别的流程怎么不冲突

| 情况 | 处理 |
| --- | --- |
| 命令到达 | 立即解析、立即执行（不进合批队列） |
| 命令的回复 | 走发送优先通道：排在所有待发的普通回复**前面**；正在发的那一条不会被截断（不会半句话） |
| 模型正在思考旧消息时，来了 `/mode` `/mute` `/unmute` `/forget` `/reset` `/ask` `/tldr` | 打断这次模型调用；旧回答作废；旧批次放回队列，按新状态重新处理（例如刚 `/mute` 就直接跳过，刚 `/forget` 就不会把旧回答里的记忆写回去） |
| 模型正在回应定向互动的目标时，来了 `/unattack` `/comfort` 等 | 打断；那批目标消息放回队列，按新状态（不再互动 / 换了目标）重新处理 |
| 正在分几条发回复时来了 `/mute` 或切到 `silent` | 剩下没发的部分不再发；`/ask` 等明确请求的回答除外 |
| 正在因为限速/熔断而等待 | `/ask` `/tldr` 立刻处理，不等；熔断中则回复"模型暂时不可用，稍后再试" |
| `/ask` 连着来几条 | 依次插队处理，最多积压 5 条 |
| 有人刷命令 | 每人每分钟最多 6 条（`guard.commandsPerMinute`），超过的静默忽略并记日志，不影响其他人 |
| 命令自己出错 | 回复"/xxx 出错了"，记日志，机器人继续工作 |

## /cron 定时消息

```
/cron 10m 内容              10 分钟后（也可 1h30m、90s、2小时、30分钟、1d）
/cron 10:00 内容            下一个 10:00（已过则明天；也可 10：00、10点、10点半、9点15分）
/cron 明天 8:00 内容        也可 今天 / 后天 / 10-22 / 2026-10-22
/cron 每天 22:00 内容       每天重复（也可 daily）
/cron 10:00 UTC-5 内容      时区写在时间后面：UTC±H[:MM]、GMT±H、+09:00、-0530、UTC、Asia/Tokyo 等；默认东八区
/cron list                  所有定时：编号、时间、内容、设置人
/cron cancel 编号           取消（只能取消自己设的）
```

到点时，内容**按原文**发到群里（保留换行），不经过模型。

规则与边界：

| 情况 | 行为 |
| --- | --- |
| 时间最近 / 最远 | 至少 5 秒后，最多一年内 |
| 钟点已过 / 正好是现在 | 顺延到明天；写了"今天"或完整日期而已过则报错 |
| 不带年份的日期已过 | 下一年的这一天 |
| 不存在的日期/时间（2-30、25:00、10:60） | 报错并回复用法 |
| 时间后面的词不是时区（如 `Tokyo`） | 当作内容的一部分 |
| 每天重复 + 夏令时（IANA 时区） | 保持当地钟点不变 |
| 很远的定时 / 电脑睡眠 / 改系统时间 | 每分钟按墙钟检查一次，不会提前或因计时器溢出误发 |
| 插件重启 | 定时库落盘；错过 10 分钟内的补发；错过更久的不发，记为"错过"；每天的跳到下一次 |
| 是否可能发两次 | 不会：到点先把它从库里移除（每天的推进到下一次）并立即写盘，再发送；崩溃最多丢这一次 |
| 内容以 `/` 开头 | 当普通文字发出，**不执行** |
| 禁言 / 静音 | 定时照发（是有人明确设下的） |
| 锁屏 / 断线 | 等能发再发；超过 `staleMinutes` 丢弃并记日志 |
| 换了服务的群 | 定时属于原来的群，回到那个群时再按上面"重启"的规则处理 |
| 数量限制 | 每人 5 个，全群 50 个；内容 500 字以内 |

## 自己写命令

配置 `commandsDir`，目录下每个 `.js`/`.mjs` 默认导出一个命令：

```js
export default {
  name: 'roll',                 // /roll
  aliases: ['骰子'],            // /骰子
  usage: '/roll [面数]',
  summary: '掷骰子',
  interrupts: false,            // true：改变了状态，需要打断正在思考的回答
  ack: undefined,               // 转给模型的命令可以先回一句（如"收到"）
  run({ args }) {
    return `${Math.ceil(Math.random() * Number(args[0] ?? 6))}`
  },
}
```

`run(call)` 拿到：

| 字段 | 说明 |
| --- | --- |
| `name` `text` `args` | 命令名、参数原文（保留换行）、按空白切开的参数 |
| `sender` `message` `chat` | 发送者 `{id, name}`、原始消息、当前群 |
| `mode` `setMode(m)` `mute(ms)` | 当前模式、切换模式、禁言（0 解除） |
| `memory.recall(id)` `memory.forget(id, topic?)` | 读 / 删成员记忆 |
| `resetContext()` `status()` | 清上下文、运行统计 |
| `cron.add(text)` `cron.list()` `cron.cancel(id)` | 定时库 |
| `commands` | 所有命令（写帮助用） |

返回值：

| 返回 | 效果 |
| --- | --- |
| `string` 或 `{ reply }` | 立即发这句话（优先通道） |
| `{ forward: { instruction, text?, effort? } }` | 插队交给模型，附带指令，必须回复；`effort` 可临时提高思考强度；有 `ack` 时先发 ack |
| `undefined` | 什么也不发 |
