## 导出范围和格式

- 共 6 组：5 个历史主会话（含 1 个已归档）及本次整理会话。未复制守护进程/子 Agent 会话、其他项目会话或微信聊天数据库。
- Markdown 是用户和助手可见文字；JSONL 是 `codex-project-share-v1` 分享格式，保留脱敏问答、工具调用/结果和回合事件，并带原文件行号。**它不是原始逐字副本，也不承诺能直接导入 Codex 恢复。**
- 移除了系统/开发者注入、隐藏推理、内部元数据、全局记忆与会话清单查询轨迹、二进制附件；本次会话的工具轨迹整体省略，避免把归档行为再次套入归档。
- 凭据、认证 URL 参数、长十六进制值已遮盖，真实微信 ID 采用包内一致的匿名标识。某些诊断哈希也会随长十六进制值被遮盖；准确文件哈希以清单和项目快照为准。
- 历史文字可能仍含参与者昵称、测试内容和问题背景。这是项目技术交接材料，不是公开发布材料。
- 原始会话文件保持不动，未搬移、删除或覆盖。本目录没有认证文件、微信数据库、解密密钥或用户长期记忆副本。
- [manifest.json](manifest.json) 记录原会话 ID、虚拟源路径 `CODEX_HOME/...`、快照时间、原始捕获字节 SHA256、导出文件 SHA256、记录数量和裁剪类型。所有 JSONL 的时间戳沿用 UTC，导出时间带 `+08:00`。
- 会话导出后仍可能继续产生新消息；导出截止时间看清单。当前整理会话的最终答复自然不在它自己的阶段快照里。

本次只新增交接资料和过程辅助文件；没有修改插件、配置、运行状态、数据库或凭据，没有启停服务或发送微信消息。
